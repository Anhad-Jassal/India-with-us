Build a complete, modern, responsive travel website called **“India With Us”**.

## 1. Website Concept

“India With Us” is a travel platform focused exclusively on **destinations within India**.

The website should allow:

1. Customers to browse and search Indian travel destinations.
2. Customers to view and purchase ready-made tour plans uploaded by the website administrator.
3. Customers to create their own customized tour plans.
4. The admin to upload, edit, delete, and manage tour plans.
5. Customers to create accounts, log in, and manage their plans/purchases.
6. Customers to contact us through a Help/Contact section.
7. The administrator to manage important website content through an admin dashboard.

The website should feel like a professional Indian travel startup, not a generic template.

---

# 2. Technology

Build this as a full-stack web application.

Use a modern, reliable stack such as:

* React / Next.js for the frontend
* Node.js for backend functionality if required
* PostgreSQL for the database
* Tailwind CSS for styling
* Proper authentication with secure password hashing
* Responsive design for desktop, tablet, and mobile

Use clean, modular, maintainable code.

If Replit has a recommended current full-stack setup, use the most stable option available.

The application must be fully functional rather than a static mockup.
